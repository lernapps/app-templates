Was steht auf dem Tisch?

Jedes Nomen hat im Französischen ein Geschlecht: le steht vor männlichen Nomen, la vor weiblichen, und vor einem Vokal wird beides zu l'. Das Geschlecht ist oft ein anderes als im Deutschen: la pomme, aber der Apfel.

Hier geht es um das Brot auf dem Tisch. Wie du sagst, dass du etwas Brot isst (du pain), steht auf der Lernlandkarte beim Teilungsartikel.

Übung

Schreib zu jedem Buchstaben das französische Wort mit seinem Artikel.

  1. Teil A der Abbildung
  2. Teil B der Abbildung
  3. Teil C der Abbildung
  4. Teil D der Abbildung
Lösung
  1. le pain
  2. la pomme
  3. le fromage
  4. l'eau

le, la oder l'?

Übung

Wähle für jede Lücke das passende Wort.

  1. Das Brot ist gut. → … pain est bon.
  2. Der Apfel ist rot. → … pomme est rouge.
  3. Das Wasser ist kalt. → …eau est froide.
Lösung
  1. Le pain est bon.
  2. La pomme est rouge.
  3. L'eau est froide.

Übung

Fülle die Lücken auf Französisch.

  1. Ich esse den Käse. → Je mange … fromage.
  2. Ich trinke das Wasser. → Je bois …eau.
Lösung
  1. Je mange le fromage.
  2. Je bois l'eau.
