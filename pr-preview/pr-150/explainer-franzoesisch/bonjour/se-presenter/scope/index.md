# Sich vorstellen

Sich vorstellen mit drei Sätzen: Je m'appelle … (ich heiße), J'ai … ans (ich bin … Jahre alt, wörtlich: ich habe …
Jahre) und Je suis de … (ich komme aus …). Vor einem Vokal wird je zu j' (j'ai). Die Formen von être im Präsens:
je suis, tu es, il/elle est, nous sommes, vous êtes, ils/elles sont.

## Gehört nicht dazu

- die Zeiten der Vergangenheit (passé composé, imparfait)
- Teilungsartikel und Mengenangaben (du pain, beaucoup de)
