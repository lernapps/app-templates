# À table !

Lebensmittel auf dem Tisch mit ihrem bestimmten Artikel: le pain (das Brot), la pomme (der Apfel), le fromage (der
Käse), l'eau (das Wasser). Jedes Nomen hat ein Geschlecht: le für männlich, la für weiblich, l' vor einem Vokal. Das
Geschlecht ist oft ein anderes als im Deutschen: la pomme, aber der Apfel.

## Gehört nicht dazu

- die Zeiten der Vergangenheit (passé composé, imparfait)
- Teilungsartikel und Mengenangaben (du pain, beaucoup de)
