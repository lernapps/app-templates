# Glossary

The quiz's terms, besides the generic ones.

## Question Bank

`src/quiz.json`, checked against `quiz.v1.schema.json`.

```arc42
:::glossary-term
id: term-question-bank
title: Question bank
definition: The quiz's title, intro, languages, sources and questions, the only file a quiz's creator writes.
:::
```

## Worksheet

What the quiz page shows without JavaScript.

```arc42
:::glossary-term
id: term-worksheet
title: Worksheet
definition: The quiz page without JavaScript, all questions followed by their solutions with background and links.
:::
```
